## 🚀 Running a Project Locally

```bash
# Clone the repo
git clone https://github.com/iamvivekmane/react-learning.git

# Move into any day's project
cd "react-learning/Day 06/react-notes-app"

# Install dependencies
npm install

# Start the dev server
npm start   # or npm run dev, depending on CRA vs Vite
```
